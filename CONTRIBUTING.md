# Contributing to Awesome AI Agent Stack

Thanks for helping build the most useful map of the AI-agent ecosystem! 🎉

## What belongs here

An entry should be:

1. **Open-source** — or have a genuinely useful free/open tier.
2. **Actively maintained** — a commit in roughly the last 6 months.
3. **Genuinely useful** — solves a real problem for people building agents, not just popular or hyped.
4. **In the right layer** — if you're unsure which layer it belongs to, say so in your PR and we'll figure it out together.

We deliberately keep each layer **curated, not exhaustive**. A shorter list people trust beats a huge list they have to filter themselves.

## How to add an entry

1. Fork the repo.
2. Add your entry to the correct section, keeping the list **alphabetical within its subsection** where one exists.
3. Use this exact format:

   ```markdown
   - [Project Name](https://github.com/org/repo) — One line, present tense: what it does and why it belongs in this layer.
   ```

4. Keep the description to **one sentence**. No marketing language ("blazingly fast", "revolutionary"). Say what it *does*.
5. Open a pull request with a title like `Add <Project> to <Layer>`.

## How to suggest without coding

Open an [issue](../../issues/new/choose) using the "Suggest a tool" template. That's completely fine — maintainers will format it.

## Removing entries

Projects that become unmaintained (no commits in ~12 months), get archived, or go closed-source will be moved out. If you spot one, open an issue.

## Quality checklist (for PRs)

- [ ] Link works and points to the canonical repo/site
- [ ] Entry is in the correct layer
- [ ] Description is one sentence, present tense, no hype
- [ ] Alphabetical order preserved (where applicable)
- [ ] No duplicate of an existing entry
